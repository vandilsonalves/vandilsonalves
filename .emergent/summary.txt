<analysis>**original_problem_statement:**
O usuário solicitou uma nova funcionalidade principal chamada **Ranking das Corridas**. O objetivo é criar um sistema dentro da plataforma onde os atletas possam cadastrar e avaliar corridas de rua com base em 5 critérios específicos (Organização, Percurso, Kit Atleta, Hidratação, Pós Prova). O sistema deve gerar rankings (Nacional, Estadual, Cidade, Mensal, Anual, Histórico) usando um algoritmo de Média Bayesiana para garantir justiça estatística. Corridas com boas avaliações devem receber selos digitais. A funcionalidade também inclui um painel de administração para gerenciar corridas e visualizar estatísticas.

**PRODUCT REQUIREMENTS:**
1.  **Cadastro de Corridas:** Permitir que administradores e donos de assessoria cadastrem corridas com campos como nome, organizador, local, data e link.
2.  **Sistema de Avaliação:**
    *   Atletas logados podem avaliar uma corrida apenas uma vez e somente após a data do evento.
    *   A avaliação é baseada em 5 critérios (IQC), cada um com nota de 1 a 5 estrelas.
    *   A nota final da corrida é a média simples dos 5 critérios.
3.  **Algoritmo de Ranking:**
    *   Utilizar **Média Bayesiana** para calcular a pontuação do ranking, evitando que corridas com poucas avaliações fiquem no topo.
    *   Uma corrida precisa de um número mínimo de avaliações (ex: 10) para aparecer no ranking.
4.  **Visualização e Filtros:**
    *   Criar uma nova página pública Ranking das Corridas.
    *   Exibir o ranking em uma tabela com filtros (Nacional, Estadual, Cidade, etc.).
    *   Mostrar a pontuação, o número de avaliações e a média de cada critério para cada corrida.
5.  **Selos e Reconhecimento:**
    *   Atribuir selos automáticos (Corrida 5 Estrelas, Top 10 Brasil, etc.) para corridas que atingirem certos critérios.
6.  **Painel de Administração:**
    *   Criar uma visão no dashboard do administrador para gerenciar corridas e visualizar estatísticas (ex: corridas mais bem avaliadas, total de avaliações).

**User's preferred language**: O idioma principal do usuário é o **Português (Brasil)**. O próximo agente DEVE responder apenas em português.
